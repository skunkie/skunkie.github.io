TorrPlay предоставляет полнофункциональный RESTful API для программного управления. Полная спецификация OpenAPI доступна по адресу [`api/api.yaml`](https://github.com/torrplay/torrplay/blob/main/api/api.yaml).

Кроме того, ознакомиться с документацией API можно в **[Scalar](/openapi/)**.

## Базовый URL

Все эндпоинты API задаются относительно:

```
http://localhost:8090
```

## Потоковая передача

Для потоковой передачи файлов из торрента укажите хеш и URL-кодированный путь к файлу:

```text
http://localhost:8090/api/v1/stream/{hash}?path={url_encoded_path}
```

Если включена аутентификация, добавьте токен воспроизведения:

```text
http://localhost:8090/api/v1/stream/{hash}?path={url_encoded_path}&token={playback_token}
```

Пример запроса:

```text
http://localhost:8090/api/v1/stream/dd8255ecdc7ca55fb0bbf81323d87062db1f6d1c?path=Big.Buck.Bunny.1080p.mp4
```

Эндпоинты `GET` и `HEAD` также принимают необязательный URL-кодированный параметр `magnet`. Он передаёт трекеры, через которые TorrPlay ищет пиров для торрента, которого ещё нет в библиотеке.

## Предзагрузка

Запустите или замените предзагрузку торрента, указав индекс либо путь к файлу. Если не передать ни одно из этих полей, TorrPlay выберет файл с индексом `0`:

```sh
curl -X PUT http://localhost:8090/api/v1/torrents/{hash}/preload \
  -H "Content-Type: application/json" \
  -d '{
    "file_index": 0,
    "playback_position_seconds": 900
  }'
```

Поле `playback_position_seconds` добавляет к началу и концу файла диапазон возле сохранённой позиции просмотра. Запрос также принимает `file_path` и необязательную magnet-ссылку в поле `magnet`.

Ответ содержит `target_bytes`, `completed_bytes`, `progress`, `download_rate`, `active_peers`, `total_peers` и один из следующих статусов:

| Статус       | Значение                                                                     |
| ------------ | ---------------------------------------------------------------------------- |
| `idle`       | Для торрента нет предзагрузки                                                |
| `queued`     | Ожидание свободного слота или памяти                                         |
| `preloading` | Загрузка выбранных диапазонов файла                                          |
| `ready`      | Все запланированные диапазоны находятся в кэше                               |
| `failed`     | Не удалось зарезервировать память или торрент перестал получать данные       |
| `evicted`    | Резерв освобождён для другой предзагрузки или после уменьшения лимита памяти |

Если воспроизведение не началось, предзагрузка со статусом `ready` хранится 10 секунд. После использования TorrPlay освобождает её, когда закроется последний поток чтения файла, включая оставленный открытым в ожидании следующего запроса. Конечный статус `failed` или `evicted` также доступен в течение 10 секунд.

## Чтение удалённого торрент-файла

`POST /api/v1/torrent-resolutions` загружает файл `.torrent` по HTTP- или HTTPS-ссылке и возвращает его метаданные, не создавая запись в базе данных. Если торрент уже есть в библиотеке, эндпоинт вернёт сохранённые метаданные без изменений:

```sh
curl -X POST http://localhost:8090/api/v1/torrent-resolutions \
  -H "Content-Type: application/json" \
  -d '{"url":"https://indexer.example/download/example.torrent"}'
```

Чтобы сохранить торрент в библиотеке, используйте `POST /api/v1/torrents`.

## Аутентификация

При включённой аутентификации учётные данные необходимо указывать в каждом защищённом запросе. Эндпоинт выдачи токенов и проверка работоспособности доступны без аутентификации. Подробности в разделе [Аутентификация](/docs/authentication).

### Базовая аутентификация

Имя пользователя и пароль указываются в каждом защищённом запросе:

```sh
curl -u your-username:your-password http://localhost:8090/api/v1/torrents
```

### Токен Bearer

Для защищённых эндпоинтов JWT-токен указывается в заголовке `Authorization`.

```sh
curl -H "Authorization: Bearer your-jwt-token" http://localhost:8090/api/v1/torrents
```

### Получение токена

```sh
curl -X POST http://localhost:8090/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=password&username=your-username&password=your-password"
```

## Пример: добавление торрента

```sh
curl -X POST http://localhost:8090/api/v1/torrents \
  -H "Content-Type: application/json" \
  -d '{
    "magnet": "magnet:?xt=urn:btih:dd8255ecdc7ca55fb0bbf81323d87062db1f6d1c&dn=Big+Buck+Bunny"
  }'
```
