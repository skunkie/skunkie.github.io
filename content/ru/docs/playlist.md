## API плейлистов

**Эндпоинт:** `GET /api/v1/playlist`

| Параметр | Тип    | Обязательный | Описание                                     |
| -------- | ------ | ------------ | -------------------------------------------- |
| `name`   | string | Нет          | Фильтрация результатов по наименованию медиа |

**Возвращает:** плейлист в формате M3U (`Content-Type: application/x-mpegURL`)

Эндпоинт возвращает плейлист M3U со ссылками на потоки всех торрентов из библиотеки TorrPlay. Список можно фильтровать по названию. Это позволяет открыть всю библиотеку в любом внешнем медиаплеере по единой ссылке.

### Формат ответа

```
#EXTM3U
#EXTINF:-1,Sintel
http://localhost:8090/api/v1/stream/08ada5a7a6183aae1e09d831df6748d566095a10?path=Sintel.mp4
```

В каждой строке `#EXTINF` содержится ссылка на стрим конкретного файла.

### Примеры использования

Открыть все торренты в VLC:

```sh
vlc "http://localhost:8090/api/v1/playlist"
```

Фильтрация плейлиста по имени:

```
GET /api/v1/playlist?name=Sintel
```

Сохранение плейлиста в файл:

```sh
curl -o torrplay.m3u http://localhost:8090/api/v1/playlist
```

### Аутентификация и совместимость с медиаплеерами

При включённой аутентификации для получения плейлиста передайте токен воспроизведения:

```sh
vlc "http://localhost:8090/api/v1/playlist?token=your-playback-token"
```

Если запросить плейлист с параметром `?token=...`, TorrPlay автоматически добавит этот токен во все ссылки на видео внутри M3U-файла. Внешний плеер сможет сразу воспроизводить файлы без повторной авторизации. Подробнее о токенах читайте в руководстве по [Аутентификации](/docs/authentication/).
