# Возможности

TorrPlay предоставляет широкий набор функций для потоковой передачи торрентов, управления локальным хранением данных, совместимости с медиасерверами и мониторинга.

## HTTP-потоковая передача

Позволяет передавать видео и другие файлы напрямую из торрента без предварительной загрузки торрента целиком. Конечная точка потоковой передачи доступна по адресу:

```
/api/v1/stream/{hash}?path={url_encoded_path}
```

При использовании базовой аутентификации конечные точки потоковой передачи не защищены аутентификацией, что обеспечивает простую интеграцию с медиаплеерами, такими как VLC, IINA или Kodi.

## DLNA / UPnP медиасервер

TorrPlay включает в себя встроенный DLNA медиасервер. Это позволяет смарт-телевизорам (LG webOS, Samsung Tizen, Sony Bravia), игровым консолям PlayStation/Xbox и другим медиаустройствам в локальной сети автоматически обнаруживать TorrPlay и воспроизводить активные торренты.

Подробные сведения о настройке приведены в разделе **[Руководство по потоковой передаче через DLNA / UPnP](/docs/dlna)**.

## Бэкенды хранения данных

TorrPlay предлагает два отдельных бэкенда хранения для управления данными торрентов.

{{< tabs "storage-backend" >}}
{{% tab "Хранение в памяти" %}}
Части торрента загружаются и кэшируются в оперативной памяти в пределах настраиваемого лимита (`max_memory`). По достижении лимита применяется политика вытеснения по принципу давности использования (Least Recently Used, LRU), при которой удаляются самые старые части.

**Преимущества:**

- Высокая производительность
- Снижение нагрузки на дисковый ввод-вывод
- Оптимально подходит для потоковой передачи

**Недостатки:**

- Данные не сохраняются после перезапуска
- Ограничение объёмом доступной оперативной памяти

{{% /tab %}}
{{% tab "Файловое хранение" %}}
Части торрента сохраняются в файловой системе, что обеспечивает постоянное хранение данных при перезапуске приложения. Расположение хранилища настраивается с помощью параметра `file_storage_path`.

**Преимущества:**

- Сохранение данных при перезапуске
- Отсутствие ограничения по объёму оперативной памяти

**Недостатки:**

- Более низкая производительность по сравнению с хранением в памяти
- Повышенная нагрузка на дисковый ввод-вывод

> [!NOTE]
> **Примечание для пользователей Windows:** в Windows TorrPlay автоматически не удаляет файлы торрента из файловой системы при удалении торрента или смене бэкенда хранения. В связи с этим может потребоваться ручная очистка.

## Метрики Prometheus и мониторинг

TorrPlay предоставляет метрики в реальном времени в формате Prometheus через конечные точки `/metrics` и `/api/system/metrics`. Пользовательские метрики отслеживают количество активных фоновых загрузок (`torrplay_downloading_torrents`), число текущих сеансов потоковой передачи (`torrplay_streaming_torrents`), количество и продолжительность HTTP-запросов, а также статистику среды выполнения Go.

Подробные сведения о настройке сбора метрик Prometheus приведены в разделе **[Руководство по метрикам и мониторингу](/docs/metrics)**.

## Получение метаданных

TorrPlay позволяет обновлять библиотеку торрентов с помощью получения метаданных (постеров, названий, категорий) из внешних источников, таких как TVDB.

### Параметры командной строки

| Флаг                    | Описание                              | Значение по умолчанию |
| ----------------------- | ------------------------------------- | --------------------- |
| `--backup <path>`       | Путь к входному файлу резервной копии | `torrplay.backup`     |
| `--output <path>`       | Путь к выходному файлу                | `torrplay.backup`     |
| `--category`            | Включение обновления категорий        | Отключено             |
| `--poster`              | Включение обновления постеров         | Отключено             |
| `--title`               | Включение обновления названий         | Отключено             |
| `--language <lang>`     | Код языка (например, `eng`, `spa`)    | —                     |
| `--provider <provider>` | Провайдер метаданных (`tvdb`)         | —                     |
| `--api-key <key>`       | Ключ API для провайдера               | —                     |

### Пример использования

```sh
./torrplay --backup torrplay.backup --poster --title --provider tvdb --api-key YOUR_API_KEY
```

## Совместимость с TorrServer

TorrPlay включает в себя конечные точки совместимости для клиентов, использующих API TorrServer. Это позволяет использовать TorrPlay в качестве полноценной замены TorrServer в уже существующих конфигурациях.

## Совместимость с qBittorrent

TorrPlay эмулирует API qBittorrent для беспрепятственной интеграции со средствами автоматизации, такими как Prowlarr, Sonarr и Radarr:

```sh
curl -X POST http://localhost:8090/api/v2/torrents/add \
  -F "urls=magnet:?xt=urn:btih:dd8255ecdc7ca55fb0bbf81323d87062db1f6d1c&dn=Big+Buck+Bunny" \
  -F "category=Movies"
```

## Приложения для мобильных и настольных платформ

Основная логика приложения реализована в виде библиотеки на языке Go (`pkg/torrplay`), которая может быть скомпилирована для мобильных приложений с помощью `gomobile` и Capacitor. Также доступно настольное приложение на базе Tauri.
