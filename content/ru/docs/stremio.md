TorrPlay поддерживает протокол [Stremio Addon Protocol v3](https://github.com/Stremio/stremio-addon-sdk). Благодаря этому TorrPlay можно подключить как пользовательский аддон напрямую в Stremio на компьютере, Android TV или телефоне.

После подключения торренты из библиотеки TorrPlay появятся в каталогах фильмов и сериалов Stremio, а видео будет воспроизводиться напрямую через встроенный HTTP-стример.

## Возможности

- **Поддержка протокола v3:** полная реализация спецификации манифеста, каталогов, метаданных и потоков Stremio.
- **Автоматическая сортировка медиа:** торренты сами распределяются по разделам **Фильмы** и **Сериалы**.
- **Определение сезонов и серий:** номера сезонов и эпизодов автоматически распознаются в именах файлов (`S01E02`, `1x05`, `ep 03`), формируя удобный список серий.
- **Поиск по библиотеке:** искать и фильтровать добавленные торренты можно в интерфейсе Stremio.
- **Безопасная аутентификация:** отдельный токен Stremio передаётся в пути URL (`/stremio/{token}/manifest.json`) или в параметре запроса `token`.
- **Прямые ссылки на потоки:** адреса вида `/stremio/play/{hash}/{fileIdx}/{filename}` содержат исходное имя файла и правильный MIME-тип, поэтому внешние плееры (ExoPlayer, VLC) воспроизводят видео без сбоев.

## Установка и подключение

### 1. Включение Stremio в настройках

По умолчанию поддержка Stremio отключена. Включить или выключить её можно двумя способами:

- **В веб-интерфейсе:** откройте **Настройки** → включите пункт **Включить Stremio**.
- **Через API:** отправьте запрос `PATCH /api/v1/settings` с телом `{"enable_stremio": true}`.

### 2. Подключение аддона в Stremio

#### Установка в один клик

В веб-интерфейсе TorrPlay откройте **Настройки** и нажмите **Установить аддон Stremio** либо перейдите по ссылке `stremio://`:

```text
stremio://<torrplay-host>:<port>/stremio/manifest.json
```

#### Ручное добавление по URL

1. Скопируйте адрес манифеста TorrPlay:
   ```text
   http://<torrplay-host>:<port>/stremio/manifest.json
   ```
2. Откройте приложение Stremio.
3. Перейдите в раздел **Community Addons**.
4. Вставьте адрес манифеста в строку поиска и нажмите **Install**.

## Аутентификация в Stremio

Если в TorrPlay включена аутентификация, в ссылках Stremio нужен отдельный токен Stremio. Его возвращает поле `stremio_token` в ответе `GET /api/v1/settings`:

```sh
curl -s -u your-username:your-password http://localhost:8090/api/v1/settings | jq -r .stremio_token
```

При Bearer-аутентификации замените `-u` на `-H "Authorization: Bearer your-jwt-token"`. Для извлечения поля в примере используется [jq](https://jqlang.org/); токен можно найти и в полном JSON-ответе.

Токен не меняется, пока вы не измените какую-либо настройку аутентификации: после этого он отзывается. Токены воспроизведения и административные токены доступа на маршрутах Stremio не принимаются.

Аддон поддерживает два варианта передачи токена:

### Токен в пути (рекомендуется)

```text
http://<torrplay-host>:<port>/stremio/<your-stremio-token>/manifest.json
```

### Токен в параметре запроса

```text
http://<torrplay-host>:<port>/stremio/manifest.json?token=<your-stremio-token>
```

Если нажать **Установить аддон Stremio** в веб-интерфейсе после авторизации, токен Stremio автоматически подставится в сформированную ссылку. Ссылки на потоки, которые получает Stremio, тоже содержат токен в пути.

## Справочник эндпоинтов Stremio

Все маршруты Stremio обслуживаются по префиксу `/stremio`:

| Эндпоинт                                    | Метод | Описание                                                       |
| ------------------------------------------- | ----- | -------------------------------------------------------------- |
| `/stremio/manifest.json`                    | `GET` | Манифест аддона с описанием возможностей, ресурсов и каталогов |
| `/stremio/{token}/manifest.json`            | `GET` | Манифест аддона с токеном аутентификации в пути URL            |
| `/stremio/catalog/{type}/{id}.json`         | `GET` | Каталог фильмов или сериалов с поддержкой поиска и пагинации   |
| `/stremio/meta/{type}/{id}.json`            | `GET` | Метаданные и список серий для указанного фильма или сериала    |
| `/stremio/stream/{type}/{id}.json`          | `GET` | Ссылки для потокового воспроизведения фильма или серии         |
| `/stremio/play/{hash}/{fileIdx}/{filename}` | `GET` | Обработчик прямого потокового вещания с поддержкой HTTP Range  |
