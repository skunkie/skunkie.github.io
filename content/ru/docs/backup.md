# Резервное копирование и восстановление

TorrPlay предоставляет конечные точки для создания резервных копий и восстановления всей библиотеки торрентов, включая метаданные, категории, постеры и хэш-суммы торрентов, с целью переноса данных между экземплярами приложения или сохранения состояния перед обновлением.

---

## Создание резервной копии

```sh
GET /api/v1/torrents/backup
```

Возвращает файл в формате JSON, содержащий метаданные всех торрентов (хэш-суммы, магнитные ссылки, названия, категории, постеры и настройки). Для сохранения на диск выполните:

```sh
curl -o torrplay.backup http://localhost:8090/api/v1/torrents/backup
```

---

## Восстановление из резервной копии

```sh
POST /api/v1/torrents/restore
```

Загрузите файл резервной копии в формате `multipart/form-data`:

```sh
curl -X POST http://localhost:8090/api/v1/torrents/restore \
  -F "file=@torrplay.backup"
```

Приложение повторно добавит все торренты из резервной копии с исходными метаданными.

---

## Обновление резервной копии метаданными

Перед восстановлением можно обновить файл резервной копии, загрузив актуальные метаданные (постеры, названия, категории) из внешних источников с помощью подкоманды `metadata` CLI.

### Доступные параметры

| Флаг               | Описание                                                       | По умолчанию                   |
| ------------------ | -------------------------------------------------------------- | ------------------------------ |
| `--backup <путь>`  | Входной файл резервной копии                                   | `torrplay.backup`              |
| `--output <путь>`  | Путь к выходному файлу                                         | `<имя_входного_файла>.updated` |
| `--category`       | Обновление категорий (Movies / Series)                         | Отключено                      |
| `--poster`         | Получение и обновление постеров                                | Отключено                      |
| `--title`          | Обновление названий из внешнего источника                      | Отключено                      |
| `--language <код>` | Трёхбуквенный код языка (`eng`, `spa`, `rus` и др.)            | —                              |
| `--provider <имя>` | Провайдер метаданных (на данный момент доступен только `tvdb`) | —                              |
| `--api-key <ключ>` | Ключ API для выбранного провайдера                             | —                              |

> **Примечание:** для флагов `--poster` и `--title` требуется указать `--api-key`.

### Пример использования

Получение постеров и названий из TheTVDB на русском языке:

```sh
./torrplay metadata \
  --backup torrplay.backup \
  --poster --title \
  --language rus \
  --provider tvdb \
  --api-key YOUR_TVDB_API_KEY
```

Результатом выполнения является файл `torrplay.backup.updated`. Укажите `--output` для задания собственного пути к выходному файлу.

## Полный процесс миграции

```mermaid
graph LR
    Inst1["Исходный экземпляр TorrPlay"] -->|1. GET /api/v1/torrents/backup| File["torrplay.backup"]
    File -->|2. Добавление метаданных: ./torrplay metadata| Updated["torrplay.backup.updated"]
    Updated -->|3. POST /api/v1/torrents/restore| Inst2["Целевой экземпляр TorrPlay"]
```

```sh
# 1. Скачивание резервной копии с исходного экземпляра
curl -o torrplay.backup http://source-host:8090/api/v1/torrents/backup

# 2. (Необязательно) Обновление метаданных
./torrplay metadata --backup torrplay.backup --poster --title --provider tvdb --api-key KEY

# 3. Восстановление на целевом экземпляре
curl -X POST http://target-host:8090/api/v1/torrents/restore \
  -F "file=@torrplay.backup.updated"
```
