TorrPlay выпускается в виде готовых инсталляторов, десктопных приложений, мобильных пакетов и автономных бинарных файлов для всех популярных ОС. Развёртывание в контейнерах описано в разделе [Запуск в Docker](/quick-start/running-with-docker/).

---

## Десктопные приложения

Десктопный клиент TorrPlay разработан на базе **Tauri** и **Next.js** и доступен для Windows, macOS и Linux.

### Приложение для macOS

На macOS приложение (`.dmg` / `.app`) использует архитектуру **Tauri Sidecar**:

- **Встроенный бэкенд:** Исполняемый файл Go (`torrplay`) встроен в пакет приложения (`TorrPlay.app/Contents/MacOS/`).
- **Управление процессами:** При старте приложения Tauri автоматически запускает бэкенд в фоновом режиме с нужными переменными окружения (`TORRPLAY_RUNNING_AS_SERVICE=true`).
- **Чистое завершение:** Tauri регистрирует системные обработчики сигналов и вызовы `atexit`, поэтому бэкенд гарантированно останавливается при выходе из приложения.

## Пакеты и инсталляторы по операционным системам

### Windows

| Тип дистрибутива          | Расширение | Способ установки                                                                                                          |
| ------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Инсталлятор WiX (MSI)** | `.msi`     | Запустите двойным щелчком мастер установки. Автоматически настраивает правила брандмауэра и службу Windows.               |
| **Инсталлятор NSIS**      | `.exe`     | Стандартный мастер установки десктопного графического приложения Tauri.                                                   |
| **Исполняемый файл**      | `.exe`     | Портативный консольный файл. Запуск из командной строки CMD/PowerShell: `.\torrplay-windows-amd64.exe --data-dir=C:\data` |

### Linux

| Тип дистрибутива                 | Расширение  | Способ установки                                                            |
| -------------------------------- | ----------- | --------------------------------------------------------------------------- |
| **Пакет Debian / Ubuntu**        | `.deb`      | `sudo dpkg -i torrplay_*.deb` или `sudo apt install ./torrplay_*.deb`       |
| **Пакет RHEL / Fedora / CentOS** | `.rpm`      | `sudo rpm -i torrplay_*.rpm` или `sudo dnf install ./torrplay_*.rpm`        |
| **Универсальный пакет AppImage** | `.AppImage` | `chmod +x TorrPlay-*.AppImage && ./TorrPlay-*.AppImage`                     |
| **Исполняемый файл**             | —           | `chmod +x torrplay-linux-amd64 && ./torrplay-linux-amd64 --data-dir=./data` |

### macOS

| Тип дистрибутива               | Расширение | Способ установки                                                                   |
| ------------------------------ | ---------- | ---------------------------------------------------------------------------------- |
| **Приложение macOS (Sidecar)** | `.dmg`     | Откройте образ `.dmg` и перетащите **TorrPlay** в системную папку `/Applications`. |
| **Исполняемый файл**           | —          | `chmod +x torrplay-darwin-arm64 && ./torrplay-darwin-arm64`                        |

> [!NOTE]
> macOS Gatekeeper может заблокировать неподписанное приложение. Чтобы разблокировать, выполните в Terminal: `xattr -c /Applications/TorrPlay.app`, затем щелкните правой кнопкой мыши → **Открыть**.

> [!TIP]
> **Ограничение на macOS:** WKWebView в Tauri не загружает HTTP-страницы из-за App Transport Security. Чтобы смотреть видео, выберите плеер (VLC, IINA и др.) в настройках Tauri: External Player → Player Name. Плеер должен быть установлен в системе.

### Android

| Тип дистрибутива                   | Расширение | Описание                                                                                                                                         |
| ---------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Установочный пакет Android APK** | `.apk`     | Готовые установочные файлы для архитектур `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86` и `universal`. Загрузите и откройте на устройстве Android. |
| **Библиотека Gomobile**            | `.aar`     | Архив библиотеки Android `pkg/torrplay` для разработчиков, для встраивания TorrPlay в собственные мобильные приложения.                          |
