TorrPlay выпускается в виде готовых инсталляторов, десктопных приложений, мобильных пакетов и автономных бинарных файлов для всех популярных ОС. Развёртывание в контейнерах описано в разделе [Запуск в Docker](/quick-start/running-with-docker/).

## Десктопные приложения

Десктопный клиент TorrPlay разработан на базе **Tauri** и **Next.js** и доступен для Windows, macOS и Linux.

Устройство приложения зависит от платформы:

- **Windows и Linux:** приложение Tauri — это клиентский интерфейс. Бэкенд TorrPlay нужно установить или запустить отдельно. По умолчанию клиент подключается к `http://localhost:8090`; адрес API можно изменить в настройках.
- **macOS:** приложение Tauri поставляется вместе с Go-бэкендом и само управляет им как sidecar-процессом, поэтому отдельная установка сервера не нужна.
- **Android:** Go-бэкенд встроен через библиотеку Gomobile и работает как служба переднего плана Android (foreground service).

Автономные бинарные файлы, системные службы, образы Docker и серверные пакеты для Linux запускают Go-бэкенд. Он обслуживает API и встроенный веб-интерфейс.

### Приложение для macOS

На macOS приложение (`.dmg` / `.app`) использует архитектуру **Tauri Sidecar**:

- **Встроенный бэкенд:** Исполняемый файл Go (`torrplay`) встроен в пакет приложения (`TorrPlay.app/Contents/MacOS/`).
- **Управление процессами:** При старте приложения Tauri автоматически запускает бэкенд в фоновом режиме с переменной окружения `TORRPLAY_RUNNING_AS_SERVICE=true`.
- **Чистое завершение:** Tauri следит за sidecar-процессом и регистрирует обработчик `atexit`, чтобы остановить бэкенд при выходе из приложения.

## Пакеты и инсталляторы по операционным системам

### Windows

| Тип дистрибутива            | Имя файла                                              | Способ установки                                                                                                          |
| --------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| **Установщик службы**       | `TorrPlay-<version>-<arch>.msi`                        | Установщик TorrPlay на базе WiX настраивает брандмауэр и регистрирует Go-бэкенд как службу Windows.                       |
| **Десктопный клиент Tauri** | `TorrPlay.Client_*.msi`, `TorrPlay.Client_*-setup.exe` | Устанавливает клиентский интерфейс. Для работы нужен отдельно запущенный бэкенд TorrPlay.                                 |
| **Исполняемый файл**        | `torrplay-windows-<arch>.exe`                          | Портативный консольный файл. Запуск из командной строки CMD/PowerShell: `.\torrplay-windows-amd64.exe --data-dir=C:\data` |

### Linux

| Тип дистрибутива                      | Имя файла                                                                   | Способ установки                                                            |
| ------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| **Бэкенд для Debian / Ubuntu**        | `torrplay_<version>_linux_<arch>.deb`                                       | `sudo dpkg -i torrplay_*.deb` или `sudo apt install ./torrplay_*.deb`       |
| **Бэкенд для RHEL / Fedora / CentOS** | `torrplay_<version>_linux_<arch>.rpm`                                       | `sudo rpm -i torrplay_*.rpm` или `sudo dnf install ./torrplay_*.rpm`        |
| **Десктопный клиент Tauri**           | `torrplay-client*.deb`, `torrplay-client*.rpm`, `torrplay-client*.AppImage` | Пакеты клиентского интерфейса; бэкенд TorrPlay запускается отдельно.        |
| **Исполняемый файл**                  | `torrplay-linux-<arch>`                                                     | `chmod +x torrplay-linux-amd64 && ./torrplay-linux-amd64 --data-dir=./data` |

### macOS

| Тип дистрибутива               | Имя файла                        | Способ установки                                                                   |
| ------------------------------ | -------------------------------- | ---------------------------------------------------------------------------------- |
| **Приложение macOS (Sidecar)** | `TorrPlay_<version>_aarch64.dmg` | Откройте образ `.dmg` и перетащите **TorrPlay** в системную папку `/Applications`. |
| **Исполняемый файл**           | `torrplay-darwin-<arch>`         | `chmod +x torrplay-darwin-arm64 && ./torrplay-darwin-arm64`                        |

> [!NOTE]
> macOS Gatekeeper может заблокировать неподписанное приложение. Чтобы разблокировать, выполните в Terminal: `xattr -c /Applications/TorrPlay.app`, затем щелкните правой кнопкой мыши → **Открыть**.

> [!TIP]
> **Ограничение на macOS:** WKWebView в Tauri не загружает HTTP-страницы из-за App Transport Security. Чтобы смотреть видео, выберите плеер (VLC, IINA и др.) в настройках Tauri: External Player → Player Name. Плеер должен быть установлен в системе.

### Android

| Тип дистрибутива                   | Имя файла                    | Описание                                                                                                                                                                                                  |
| ---------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Установочный пакет Android APK** | `torrplay-android-<abi>.apk` | Автономное приложение со встроенным Go-бэкендом, который работает как служба переднего плана Android (foreground service). Доступны пакеты для `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86` и `universal`. |
| **Библиотека Gomobile**            | `torrplay.aar`               | Архив Android с логикой `pkg/torrplay` для встраивания TorrPlay в собственные мобильные приложения.                                                                                                       |
