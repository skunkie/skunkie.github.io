В TorrPlay встроен сервер [Model Context Protocol (MCP)](https://modelcontextprotocol.io/). С его помощью ИИ-ассистенты (Claude Desktop, Cursor и другие агенты) могут напрямую управлять запущенным TorrPlay.

Через MCP ассистенты умеют просматривать раздачи, проверять статус стриминга и кэша, добавлять или удалять торренты, а также генерировать ссылки на видео в диалоге.

## Архитектура

Сервер MCP запускается отдельной командой CLI:

```sh
torrplay mcp [flags]
```

- **Изоляция процессов:** MCP-сервер работает с TorrPlay через HTTP/REST API и не обращается напрямую к файлам базы данных, что исключает блокировки и конфликты.
- **Транспорты:**
  - `stdio` (по умолчанию): обмен данными через стандартные потоки ввода/вывода (stdin/stdout), подходит для локальных клиентов вроде Claude Desktop.
  - `sse`: передача событий Server-Sent Events по протоколу HTTP с привязкой к локальному адресу loopback.

## Параметры командной строки и переменные окружения

| Флаг         | Переменная окружения | По умолчанию            | Описание                                                      |
| ------------ | -------------------- | ----------------------- | ------------------------------------------------------------- |
| `-url`       | `TORRPLAY_URL`       | `http://127.0.0.1:8090` | Адрес работающего сервера TorrPlay                            |
| `-token`     | `TORRPLAY_TOKEN`     | —                       | Токен доступа или JWT (нужен при включённой аутентификации)   |
| `-transport` | —                    | `stdio`                 | Протокол транспорта: `stdio` или `sse`                        |
| `-addr`      | —                    | `127.0.0.1:8091`        | Локальный адрес и порт для прослушивания при транспорте `sse` |

## Доступные возможности

### Инструменты (Tools)

- `list_torrents`: вывод списка активных и сохранённых торрентов со статусом, прогрессом и перечнем файлов.
- `get_torrent`: получение подробных метаданных, состояния кэша частей и структуры файлов выбранного торрента.
- `add_torrent`: добавление торрента по magnet-ссылке или хэшу.
- `delete_torrent`: удаление торрента и освобождение занятой им оперативной памяти.
- `update_torrent`: изменение метаданных (название, категория, обложка).
- `get_stream_url`: создание прямых HTTP-ссылок на видео с действующими токенами воспроизведения.

### Ресурсы (Resources)

- `torrplay://torrents`: актуальный список всех торрентов библиотеки.
- `torrplay://torrents/{hash}`: подробное состояние конкретного торрента.
- `torrplay://metrics/memory`: статистика использования памяти под кэш частей и вытеснения LRU.

### Шаблоны запросов (Prompts)

- `identify-video-files`: поиск основного видеофайла и подходящих звуковых дорожек в раздачах с несколькими файлами.
- `diagnose-stream-buffer`: оценка позиций чтения, буфера предзагрузки и скорости скачивания для диагностики задержек.

## Настройка в Claude Desktop

Чтобы подключить TorrPlay MCP к [Claude Desktop](https://claude.ai/download), добавьте следующую конфигурацию в файл `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "torrplay": {
      "command": "/usr/local/bin/torrplay",
      "args": ["mcp"],
      "env": {
        "TORRPLAY_URL": "http://127.0.0.1:8090",
        "TORRPLAY_TOKEN": "your-auth-token-if-enabled"
      }
    }
  }
}
```

Укажите вместо `/usr/local/bin/torrplay` путь к исполняемому файлу TorrPlay в вашей системе. После сохранения перезапустите Claude Desktop — инструменты TorrPlay появятся в списке доступных действий.

## Запуск транспорта SSE

Для клиентов и агентов, работающих по протоколу SSE:

```sh
torrplay mcp -transport sse -addr 127.0.0.1:8091 -url http://127.0.0.1:8090
```

> [!IMPORTANT]
> Для безопасности транспорт SSE слушает только loopback-интерфейс (`127.0.0.1`). Если нужен доступ по сети, настройте защищённый reverse proxy или TLS-туннель.
