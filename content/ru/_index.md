TorrPlay — приложение для потоковой передачи торрентов с управляемым кэшированием частей в оперативной памяти. Оно позволяет смотреть видео по HTTP без ожидания полной загрузки торрента.

## Основные возможности

- **Стриминг по HTTP и предзагрузка** — воспроизведение видео напрямую из торрентов с предварительной буферизацией
- **Умное кэширование в памяти** — хранение частей торрента в оперативной памяти с автоматическим вытеснением по LRU
- **Два бэкенда хранения** — оперативная память (по умолчанию) или постоянное хранение на диске
- **Фоновая загрузка** — скачивание торрентов на диск в фоновом режиме с автоматической паузой при просмотре
- **Протокол Stremio Addon** — нативная интеграция в Stremio v3 с каталогами фильмов/сериалов и структурой серий
- **Model Context Protocol (MCP)** — встроенный сервер для взаимодействия с ИИ-ассистентами через транспорты stdio и SSE
- **Веб-клиент и видеоплеер** — переключение звуковых дорожек (AC-3, E-AC-3, DTS через WASM) и чтение встроенных субтитров
- **Приложения для ПК и смартфонов** — нативные приложения на базе Tauri (Windows, macOS, Linux) и Capacitor (Android)
- **Медиасервер DLNA / UPnP** — навигация по категориям и потоковая передача на смарт-ТВ и плееры в локальной сети
- **RESTful API** — полнофункциональный API со спецификацией OpenAPI
- **Метрики Prometheus** — мониторинг состояния сервиса в реальном времени через эндпоинт `/metrics`
- **Совместимость с TorrServer и qBittorrent** — работа с Kodi, TorrServe, Prowlarr, Sonarr и Radarr
- **Аутентификация и токены воспроизведения** — делегированные токены для внешних плееров, Basic Auth и JWT Bearer
- **Резервное копирование и перенос** — экспорт и перенос библиотеки торрентов между серверами
