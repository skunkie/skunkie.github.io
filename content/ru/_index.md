# Обзор

TorrPlay — приложение для потоковой передачи торрентов с управляемым хранением частей в оперативной памяти. Приложение позволяет транслировать содержимое торрента по HTTP без предварительной загрузки торрента целиком.

## Основные возможности

- **HTTP-потоковая передача** — потоковая передача видео и других файлов напрямую из торрента
- **Управляемое хранение в памяти** — интеллектуальное кэширование частей торрента в оперативной памяти с применением политики вытеснения LRU
- **Два бэкенда хранения** — хранение в памяти (по умолчанию) или постоянное файловое хранение
- **Фоновая загрузка** — автоматическая загрузка торрентов с файловым хранением в фоновом режиме
- **Веб-интерфейс** — простой интерфейс для управления торрентами
- **Приложения для настольных и мобильных платформ** — нативные приложения на базе Tauri (Windows, macOS, Linux) и Capacitor (Android)
- **Медиасервер DLNA / UPnP** — потоковая передача на смарт-телевизоры и медиаплееры в локальной сети
- **RESTful API** — полнофункциональный API со спецификацией OpenAPI
- **Метрики Prometheus** — мониторинг состояния приложения в реальном времени через конечную точку `/metrics`
- **Совместимость с TorrServer** — поддержка клиентов, использующих API TorrServer
- **Совместимость с qBittorrent** — работа с Prowlarr, Sonarr и Radarr
- **Аутентификация** — поддержка базовой аутентификации и JWT Bearer-токенов
- **Резервное копирование и восстановление** — экспорт и импорт библиотеки торрентов между экземплярами приложения
