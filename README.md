# TorrPlay Documentation

Hugo-based documentation site for [TorrPlay](https://github.com/torrplay/torrplay), a torrent streaming application.

## Quick Start

```sh
# Clone the repository
git clone --recursive https://github.com/torrplay/torrplay.github.io.git
cd torrplay.github.io

# Build the site
hugo

# Serve locally
hugo server
```

Requires Hugo extended v0.164.0+.
